# Project Rules

Always consult Context7 before generating code that uses:

- pydantic
- pydantic-settings
- typer
- openai-whisper
- ollama
- httpx
- pymupdf
- pandas
- openpyxl
- loguru
- pytest
- pytest-cov
- ruff

Prefer current official documentation over model memory.

When generating configuration files:

- verify syntax against Context7
- verify package versions against Context7
- verify APIs against Context7
